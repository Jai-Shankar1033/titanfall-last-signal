# Assets and licensing

- **Sprites:** drawn in code from string pixel maps in `index.html`. Original work.
- **Backgrounds and effects:** generated on the canvas at runtime. Original work.
- **Music and sound effects:** synthesized with the Web Audio API at runtime. No audio files.
- **Fonts:** the system monospace font; nothing is bundled.
- **Screenshots** in `assets/screenshots/`: generated by `npm run screenshots` from the game code.

No third-party assets are used, so no attribution is required. The game is inspired by the classic run-and-gun genre but contains no copied characters, sprites, music or level layouts.
