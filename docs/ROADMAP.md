# Roadmap

Highest priority is real-world feedback.

1. **Playtest and tune bosses.** Check telegraph timings, root and beam lanes, and Level 3 pacing with real players.
2. **Animation.** Fuller run cycle for Rook, boss attack animations, better explosions and pickups.
3. **Mobile.** Drag-to-reposition buttons, better portrait support, real-device tuning.
4. **Audio.** Richer sound design and a mix pass once players can describe what sounds weak.
5. **Content.** More secret rooms and logs, an intro, a tutorial, a forgiving difficulty mode.
6. **Engineering.** Split the file into modules with a build step, measure frame rate, add browser-based end-to-end tests.
